        出厂报告
        报告数据规则
        • 报告格式可以固定，测量值、状态帧、参数值和 PASS/WARNING 结论不能固定。
        • 正式报告只读取同一整机 CN、同一左右臂 Profile、已链接的测试证据。
        • 缺少 active standard 要求的数据时，报告会列出补测项；新版标准不再要求的数据应从报告标准移除。
        • 当前右臂 J1-J8 TIMEOUT=5000；左臂 J1-J4=1000、J5-J8=5000。报告数值仍必须来自同 CN、同侧实测证据。
        • CAN / ESC / MST ID 在报告中使用 0x05 这类十六进制格式。
