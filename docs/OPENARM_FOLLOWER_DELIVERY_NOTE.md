## 三、出厂前已完成的工位自动检测项目

本次交付前，已依据当前工作台能力执行并复核以下自动检测项目：

1. `CAN ID / Receiver ID` 映射检查  
   目的：确认整条机械臂所有节点 ID 唯一，且与配置表一致。

2. `CAN 2.0 / 1 Mbps` 配置检查  
   目的：确认全关节通信参数一致，满足当前工位与 OpenARM 基础测试要求。

3. 整臂节点扫描与总线盘点  
   目的：确认所有关节在线，无缺失节点、无重复 ID、无意外节点。

4. 参数一致性检查  
   目的：复核每个关节的 `ESC_ID / MST_ID / CTRL_MODE / TIMEOUT / can_br` 以及工位纳入检查的关键参数项。

5. 逐关节命令链路检查  
   目的：确认各关节可正确响应基础 CAN 命令链路，至少包括 `enable / disable`。

6. 连续复扫稳定性检查  
   目的：确认整臂通信无明显偶发掉线、无明显参数漂移。

7. 基础运动测试  
   目的：确认电机基础动作可执行，电机本体在当前工位环境下运行正常。

### 5.2 配置说明

1. 节点 CAN ID：控制端向电机发送控制指令所使用的 ID。  
2. 状态回复 Receiver ID：电机向控制端回传状态信息所使用的 ID。  
3. 同一 CAN 总线上严禁出现重复的 CAN ID 或 Receiver ID。  
4. 如需修改任一 ID，请同步调整上位机 / 控制程序中的对应参数。  

### 5.3 CAN ID 修改说明

本机械臂出厂前已完成 CAN ID 配置。以下流程仅在客户确有修改需求时适用：

推荐修改流程：

1. 断开除目标电机外的所有 CAN 设备。  
2. 给单个电机上电。  
3. 使用 CAN 配置工具读取当前节点 CAN ID。  
4. 设置新的节点 CAN ID 及 Receiver ID。  
5. 保存参数并断电。  
6. 重新上电后再次读取 ID，确认修改成功。  
7. 按上述流程逐一配置其他电机。  

注意事项：

- 修改过程中避免多电机同时在线。
- 修改完成后必须进行通信验证及低速运动测试。
- 建议妥善保存出厂配置记录，以便后续问题排查。

## 六、机械臂零位校准说明

⚠ 在未完成零位校准前运行演示程序、自动运动程序或大范围联动动作，可能导致机械臂自碰撞、结构过载或触发电机保护。

零位校准将直接影响：

- 机械臂初始姿态
- 正向与逆向运动学计算结果
- 演示程序与自动运动程序的安全性

建议操作流程：

1. 机械臂断电。  
2. 手动将各关节调整至 OpenARM 官方推荐的零位姿态。  
3. 通电后执行零位设置 / 零位校准指令。  
4. 保存零位参数。  
5. 断电并重新上电，确认零位状态正确。  

说明：

- 对于夹爪，OpenARM 官方默认采用闭合位置作为零位。
- 若为 Leader / Follower 双臂系统，应分别对各机械臂执行独立零位校准。

## 七、调试与演示程序运行顺序建议

建议严格按照以下顺序进行调试与验证：

1. 单关节低速运动测试。  
2. 多关节小角度联动测试。  
3. 再次核对零位设置是否正确。  
4. 运行官方示例程序或演示程序。  
5. 最后进行大范围或高速运动测试。
