## 快速开始

### 1. 安装依赖

```bash
# 基础依赖
pip install -r requirements.txt

# Web界面依赖
pip install -r web/requirements.txt
```

### 2. 启动Web服务

```bash
# 使用启动脚本（推荐）
./start_web.sh

# 或手动启动
cd web
python app.py
```

### 3. 访问界面

在浏览器中打开: http://localhost:5000

## 界面说明

### 连接配置区
- **串口设备**: 输入串口路径（Linux: `/dev/ttyUSB0`, Windows: `COM3`）
- **波特率**: 选择波特率（默认115200）
- **连接按钮**: 建立串口连接
- **断开按钮**: 断开串口连接
- **状态指示器**: 显示连接状态（已连接/未连接）

### 电机配置区
- **电机ID**: 设置电机ID（1-127）
- **电机型号**: 从下拉列表选择电机型号
- **主机ID**: 设置MasterID（通常为0）
- **添加电机按钮**: 将电机配置添加到系统中

### 电机列表区
- 显示已添加的所有电机
- 显示每个电机的状态
- 点击"刷新列表"更新显示

### 电机控制区
- **选择电机**: 下拉选择要控制的电机
- **控制模式**: 选择控制模式
  - MIT模式: 阻抗控制，可调节Kp/Kd
  - 位置+速度模式: 同时控制位置和速度
  - 速度模式: 纯速度控制
  - 力矩+位置模式: 混合控制

#### MIT模式参数
- **Kp**: 位置比例增益（0-500）
- **Kd**: 速度微分增益（0-5）
- **位置**: 目标位置（rad）
- **速度**: 目标速度（rad/s）
- **扭矩**: 目标扭矩（Nm）

#### 速度模式参数
- **目标速度**: 设置电机转速（rad/s）
- **发送速度指令**: 发送控制命令
- **停止**: 立即停止电机

#### 位置+速度模式参数
- **目标位置**: 设置电机目标位置（rad）
- **最大速度**: 设置运动最大速度（rad/s）
- **移动到位置**: 执行位置运动

### 操作按钮
- **✅ 使能**: 使能选中电机
- **❌ 失能**: 失能选中电机
- **🔄 设置零位**: 将当前位置设为零位

### 实时监控区
- **开始监控**: 启动实时数据更新
- **停止监控**: 停止实时数据更新
- **监控状态**: 显示监控是否运行

#### 状态显示
- **位置**: 当前位置（rad）
- **速度**: 当前速度（rad/s）
- **扭矩**: 当前扭矩（Nm）
- **MOS温度**: MOS管温度（°C）
- **线圈温度**: 电机线圈温度（°C）
- **状态**: 电机状态
  - 绿色: 正常
  - 橙色: 警告
  - 红色: 错误

### 操作日志区
- 显示所有操作记录
- 不同操作用颜色标识:
  - 绿色: 成功
  - 红色: 错误
  - 黄色: 警告
  - 蓝色: 信息
- **清空日志**: 清除所有日志记录

## 功能详解

### 串口连接管理

1. 确认串口设备路径
2. 选择合适的波特率
3. 点击"连接"按钮
4. 查看状态指示器确认连接成功

### 电机ID配置

1. 输入电机ID（通常在电机标签上）
2. 选择对应的电机型号
3. 设置MasterID（推荐使用0）
4. 点击"添加电机"
5. 电机会出现在电机列表中

### MIT控制模式

MIT模式提供精确的阻抗控制：

**参数说明:**
- **Kp**: 决定位置控制的"硬度"，值越大，位置控制越硬
- **Kd**: 决定速度控制的阻尼，值越大，速度阻尼越大

**使用步骤:**
1. 选择"MIT"模式
2. 调节Kp和Kd参数
3. 设置目标位置、速度、扭矩
4. 观察实时状态反馈

**参数建议:**
- 柔性控制: Kp=10-50, Kd=0.1-0.5
- 标准控制: Kp=50-100, Kd=0.5-1.0
- 刚性控制: Kp=100-500, Kd=1.0-5.0

### 速度控制模式

适合需要精确速度控制的应用：

**使用步骤:**
1. 选择"速度模式"
2. 输入目标速度
3. 点击"发送速度指令"
4. 观察速度反馈

**注意事项:**
- 确保速度在电机规格范围内
- 监控温度，防止过热

### 位置+速度控制模式

适合需要精确位置控制的应用：

**使用步骤:**
1. 选择"位置+速度模式"
2. 设置目标位置
3. 设置最大速度限制
4. 点击"移动到位置"
5. 等待到达目标位置

**建议:**
- 首次使用时，用较小的速度（如1 rad/s）
- 确认运动方向正确后再提高速度

### 实时监控

实时监控提供100ms刷新的电机状态：

**监控数据:**
- 位置、速度、扭矩的实时值
- MOS管和线圈温度
- 电机运行状态

**监控建议:**
- 调试时开启监控
- 长时间运行时监控温度
- 出现异常时立即检查状态

## 常见问题

### 1. 无法连接到串口

**可能原因:**
- 串口路径错误
- 串口被其他程序占用
- 权限不足

**解决方法:**
- 检查串口路径是否正确
- 关闭其他使用串口的程序
- 添加用户到dialout组（Linux）

```bash
sudo usermod -a -G dialout $USER
# 重新登录后生效
```

### 2. 电机无法使能

**可能原因:**
- 电机未添加到系统
- 串口未连接
- 电机ID冲突

**解决方法:**
- 先添加电机
- 确认串口已连接
- 使用不同的电机ID

### 3. 电机运动异常

**可能原因:**
- 电机型号选择错误
- 参数设置不当
- 电机过载

**解决方法:**
- 确认电机型号
- 降低控制参数值
- 检查负载是否正常

### 4. 温度过高

**可能原因:**
- 负载过大
- 长时间高速运行
- 散热不良

**解决方法:**
- 降低负载
- 限制运行速度
- 改善散热条件

### 5. 实时监控无数据

**可能原因:**
- 监控未启动
- WebSocket连接失败
- 电机未使能

**解决方法:**
- 点击"开始监控"
- 检查浏览器控制台错误
- 先使能电机

### 6. Windows系统串口

Windows系统串口路径格式:
- COM1, COM2, COM3, ...

**示例:**
```text
串口设备: COM3
波特率: 115200
```

## 安全提示

⚠️ **重要安全提示:**

1. **使能前检查**: 确保电机已正确安装，负载正常
2. **温度监控**: 长时间运行必须监控温度
3. **急停准备**: 始终准备好失能电机
4. **参数渐进**: 首次使用时用保守参数，逐步调整
5. **负载限制**: 不要超过电机额定负载
6. **散热保障**: 确保电机有良好的散热条件
